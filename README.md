# Telco-Customer-Churn-Prediction
Bu proje, bir telekomünikasyon şirketinin müşteri verilerini kullanarak hizmeti bırakma (churn) ihtimalini tahmin etmeyi amaçlamaktadır. Python ve makine öğrenmesi teknikleriyle gerçekleştirilen bu çalışmada, veri ön işleme, modelleme ve değerlendirme adımları sistematik bir şekilde uygulanmıştır.

Veri Seti: Kaggle - Telco Customer Churn

Hedef: Müşterilerin hizmeti bırakıp bırakmayacağını tahmin etmek

Kullanılan Modeller: Logistic Regression, Random Forest, XGBoost

Performans Ölçütleri: Accuracy, Precision, Recall, ROC AUC

En Başarılı Model: XGBoost

En Önemli Değişkenler: Contract, Tenure, Monthly Charges
